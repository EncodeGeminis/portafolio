Estructuras de Datos: Listas, Pilas y HashMaps

← Volver a artículos

Las estructuras de datos te permiten organizar la información para accederla y modificarla eficientemente.

📋 Listas


List frutas = new ArrayList<>();
frutas.add("Manzana");
frutas.get(0); // Devuelve "Manzana"

📚 Pilas

Último en entrar, primero en salir (LIFO).


Stack pila = new Stack<>();
pila.push(10);
pila.pop(); // Devuelve 10

🔑 HashMaps

Claves y valores, ideal para búsquedas rápidas.


Map edades = new HashMap<>();
edades.put("Juan", 25);
edades.get("Juan"); // Devuelve 25

✅ Conclusión

Usar la estructura adecuada mejora el rendimiento y claridad de tu código. En entrevistas, estas son esenciales.
