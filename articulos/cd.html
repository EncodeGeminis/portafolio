¿Qué es Continuous Delivery?

← Volver a artículos

Continuous Delivery (CD) es una práctica donde cada cambio en el código puede ser desplegado automáticamente en producción.

🔁 CI vs CD

  • CI: Automatiza pruebas y builds
  • CD: Automatiza el deploy

🛠️ Herramientas comunes

  • GitHub Actions
  • GitLab CI/CD
  • Jenkins

🚀 Ejemplo: GitHub Actions


name: Build and Deploy
on: push
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - run: mvn clean install

✅ Conclusión

Con CD ganas velocidad y seguridad en los despliegues, ideal para equipos ágiles y startups.
