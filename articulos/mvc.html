¿Qué es MVC?

← Volver a artículos

El patrón MVC (Modelo-Vista-Controlador) es una arquitectura que separa la lógica de negocio, la presentación y el control de flujo en aplicaciones.

🔧 1. Modelo

El modelo representa la lógica del negocio y los datos de la aplicación. Por ejemplo, en una app de usuarios, la clase `Usuario` es parte del modelo. 


// Modelo en Java
public class Usuario {
    private String nombre;
    private int edad;

    // Getters y setters
}

🖥️ 2. Vista

Es la interfaz con la que interactúa el usuario. En aplicaciones web, normalmente es HTML, Thymeleaf o algún framework frontend.

🧠 3. Controlador

El controlador gestiona las peticiones del usuario, actualiza el modelo y decide qué vista mostrar. 


// Controlador en Spring Boot
@Controller
public class UsuarioController {
    @GetMapping("/usuarios")
    public String mostrarUsuarios(Model model) {
        model.addAttribute("usuarios", usuarioService.obtenerTodos());
        return "usuarios";
    }
}

🎯 Conclusión

MVC mejora la organización del código y facilita el mantenimiento de las aplicaciones. Es ampliamente utilizado en frameworks como Spring, Angular y ASP.NET.
