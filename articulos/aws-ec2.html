Sube tu backend a AWS EC2

← Volver a artículos

Amazon EC2 permite alojar servidores virtuales para ejecutar tus apps backend.

🧰 Requisitos

  • Cuenta en AWS
  • Llave PEM descargada
  • Jar de tu proyecto Spring

🔌 Pasos rápidos

  1. Crea una instancia EC2 (Amazon Linux o Ubuntu)
  2. Conéctate por SSH con la llave
  3. Instala Java: sudo apt install openjdk-17-jdk
  4. Sube tu .jar con scp o Git
  5. Corre con: java -jar app.jar

🌐 Abre el puerto 8080

Desde el panel de Seguridad → Grupos → Reglas de entrada.

✅ Conclusión

EC2 te da control total sobre el despliegue. Es ideal para aprender a administrar entornos reales.
