¿Qué son las pruebas unitarias?

← Volver a artículos

Las pruebas unitarias validan que las partes pequeñas de tu código funcionen como se espera.

🔧 ¿Qué es JUnit?

Es el framework de testing más popular en Java. Viene integrado en Spring Boot con Spring Test.

🧪 Ejemplo simple


public class Calculadora {
    public int suma(int a, int b) {
        return a + b;
    }
}

@Test
public void testSuma() {
    Calculadora calc = new Calculadora();
    assertEquals(5, calc.suma(2, 3));
}

⚙️ En Spring Boot


@SpringBootTest
public class UsuarioServiceTest {
    @Autowired
    UsuarioService usuarioService;

    @Test
    void testGuardarUsuario() {
        Usuario nuevo = new Usuario("Juan", 20);
        Usuario guardado = usuarioService.guardar(nuevo);
        assertNotNull(guardado.getId());
    }
}

✅ Conclusión

Con pruebas unitarias detectas errores antes, automatizas validaciones y mejoras la confianza en tus cambios.
