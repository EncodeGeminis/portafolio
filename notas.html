💻 Comandos de Git más usados

git init

Inicia un nuevo repositorio en el directorio actual.

git add .

Agrega todos los cambios al área de preparación.

git commit -m "mensaje"

Guarda los cambios con un mensaje descriptivo.

git push origin main

Envía tus commits al repositorio remoto (rama main).

git pull

Descarga y fusiona los cambios del repositorio remoto.

git status

Muestra el estado actual del repositorio.

☕ Conceptos clave de Java

List<String> lista = new ArrayList<>();

Lista ordenada que permite elementos duplicados.

for (String item : lista) { ... }

Bucle mejorado for-each para recorrer colecciones.

private String nombre;

Ejemplo de encapsulación: restringe el acceso a atributos.

📋 Scrum básico

Roles

Product Owner: define qué se construye.
Scrum Master: guía al equipo y elimina obstáculos.
Equipo de desarrollo: construye el producto.

Eventos

Sprint: ciclo de trabajo (1-4 semanas).
Daily Scrum: reunión diaria para sincronizar.
Sprint Review: revisión del incremento.
Retrospectiva: mejora continua del proceso.

Artefactos

Product Backlog: lista priorizada de requisitos.
Sprint Backlog: tareas seleccionadas para el Sprint.
Incremento: resultado funcional entregable.

Principio clave

Scrum se basa en la transparencia, inspección y adaptación para mejorar continuamente el producto y el equipo.
